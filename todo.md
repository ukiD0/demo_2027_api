ТРЕБОВАНИЯ К РАЗРАБОТКЕ API

Общая постановка задачи
Разработайте API, который возвращает список заметок из базы данных. Перед
отправкой клиенту данные должны быть обработаны по правилам, описанным ниже.
1. Структура таблицы базы данных
Создайте таблицу notes (Заметки) со следующей структурой:
Имя поля Тип данных Первичный/внешний

ключ
Id (Код) целое число или строка первичный ключ
Title (Заголовок) строка
Content (Содержание) строка
Id_user (Код пользователя) целое число или строка внешний ключ
created_at (Дата создания) Дата
Добавьте в таблицу не менее 3–5 тестовых записей.

2.1. Эндпоинт
GET /notes (или /api/notes)

4. Состав тестов коллекции
Чтобы убедиться, что API работает корректно и клиент может правильно
обработать ответ, в коллекцию необходимо добавить следующие тесты:
 Тест на статус 200 — проверяет, что при штатной работе сервер возвращает
код успеха.
 Тест на статус 500 — проверяет, что при внутренней ошибке сервер явно
сообщает об этом кодом 500.
 Тест на валидность JSON — проверяет, что сервер всегда возвращает данные
в формате JSON.
